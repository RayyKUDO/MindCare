Mengapa MindCare?

MindCare merupakan website untuk memprediksi dan pencegahan penyakit Alzheimer dengan menggunakan Machine Learning.

Bagaimana Cara Kerjanya?

1

Data Collection

Mengumpulkan data kesehatan pasien dengan fitur-fitur yang relevan

2

Preprocessing

Imputasi missing values dengan mean, feature scaling dengan StandardScaler, dan SMOTE untuk balancing data

3

Model Training

Random Forest dengan 100 trees, random_state=42

4

Deployment

Model di-deploy dalam web app untuk prediksi real-time
