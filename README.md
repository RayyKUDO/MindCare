# MindCare
Website Prediksi dan Pencegahan Penyakit Alzheimer Menggunakan Metode Random Forest
Proyek ini merupakan proyek tim yang dikembangkan sebagai bagian dari tugas akademik

## Kontribusi Saya
- Pengembangan backend menggunakan Python
- Implementasi logika pemrosesan data untuk menghasilkan hasil prediksi
- Integrasi backend dengan antarmuka web
- Pengujian fungsionalitas backend

## Teknologi
- Python
- Flask
